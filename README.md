## 📥 Installation
To install and run the Terminal Typing Test, follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/51B3/terminal_typing_test.git
cd terminal_typing_test
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

3. Execute the program:
```bash
python main.py
```

---

## 🎯 How It Works

1. The program selects random words from the built-in list.
2. The user begins to enter the suggested text in the terminal.
3. After completing the input, the program analyzes the results:
   - Typing speed (Characters Per Minute, Words Per Minute).
   - Accuracy (percentage of correctly entered characters).
   - Total time spent.
